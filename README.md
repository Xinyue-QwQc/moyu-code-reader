# 🍅 番茄小说 · VS Code 原生阅读器

在 VS Code 里浏览番茄书城、搜索、书架和历史记录，使用**真正的 VS Code 文本编辑器**阅读小说。书城、扫码登录和书评保留在 Webview；小说正文不再使用网页阅读页。

## 阅读：每页 1–50 章，一个原生编辑器文件

- 从书城详情点「开始阅读」，或从侧边栏、书架、历史记录直接打开。
- 默认**一章一个完整的只读文本文件**，也可把连续多章合并到同一文件；保留标题与原文段落，上下连续滚动，没有网页式分页、左右点击翻页或浮动工具栏。
- **默认**字体、字号、行距、背景、行号、缩略图、滚动条、光标与选区直接使用原生编辑器，遵循现有的 VS Code 编辑器配置。扩展不会修改全局 `editor.*` 设置。
- 选中、复制、`Ctrl+F`、`Ctrl+G`、`PageUp` / `PageDown`、`Home` / `End`、分屏等保留 VS Code 原生行为。
- 右侧**原生缩略图默认开启**，展示当前文件的全部章节；可以拖动缩略图、滚动条或使用目录 / 原生大纲跳转。只对小说设置缩略图默认值，不改变普通代码的设置。
- 自动换行同样遵循编辑器设置；需要时用原生 `Alt+Z`，或状态栏阅读菜单的「切换自动换行」。
- 切章、关闭后重开、重启后续读会恢复章节、光标与滚动位置。本地进度不需要登录；登录后仍支持原有的云端章节进度同步。

### 底部状态栏

阅读时，右下方显示：

**阅读菜单 · 上一页 · 本页章节范围 / 总章数 · 页内进度 · 下一页 · 每页 N 章 · 设置**

- **阅读菜单**：书城、书架、本书详情、书评、自动换行及高亮开关。
- **章节序号 / 进度**：点击打开 VS Code 原生可搜索目录，支持按章节名、序号、卷名筛选。
- **每页 N 章**：直接选择 1、3、5、10、20、50 章或输入 1–50 的自定义整数。
- **设置**：直接调整小说每页章节数、缩略图、字体、字号、行高及配色；「更多设置」打开高亮开关、颜色、强度和关键词，不需要编辑配置文件。
- 切回普通代码文件后，阅读专用控件自动隐藏。

上一页 / 下一页快捷键：Windows / Linux `Ctrl+Alt+PageUp`、`Ctrl+Alt+PageDown`；macOS `Cmd+Alt+PageUp`、`Cmd+Alt+PageDown`。仅在小说编辑器有焦点时生效，不占用普通代码编辑快捷键。

### 一页合并多章

例如设置为 **每页 3 章**，文件依次包含第 **1–3、4–6、7–9** 章。每个文件是完整的原生文本页，章节之间用空行分隔，缩略图包含所有正文；最后一页只显示实际剩余章节。

- 修改章节数后，当前文件立即重组，**保持正在阅读的章节及章内位置**，不跳回第一章。
- 目录选择某章会跳到所属合并文件中的对应位置，不仅仅打开该页开头。
- 在一个文件内滚动到下一章时，书架和历史记录会记录**实际看到的章节**；重启后按这个位置续读。
- 请求按目录顺序合并，最多同时加载四章。任一章节加载失败不替换当前正在阅读的文件，可重试；不会静默丢掉中间章节。

## 自定义字体与配色

点击阅读页右下角 **「设置」**：

- **字体**：填写系统已安装的字体名称，也支持逗号分隔的字体列表，例如 `Consolas, "Microsoft YaHei", monospace`。
- **字号 / 行高**：小说可独立设置字号和行距。行高支持像素、字号倍数和原生自动计算；留空或点击「恢复字体跟随 VS Code」恢复默认。
- 字体使用 VS Code 官方的 `[fanqie-novel]` **语言专属设置**，不是网页 CSS 模拟；不会改动其他代码文件的字体，即使分屏阅读也各自生效。
- **配色方案**：跟随主题、柔和、暖色、冷色；支持单独自定义正文、对话、单引号内容和人物 / 关键词颜色。明暗主题切换自动适配。
- **正文行底色**：可选项，默认透明。为保留原生编辑器且不影响普通代码页，只改变正文行底色；行号区、缩略图和正文外空白区仍沿用 VS Code 主题，不假装支持整页独立主题。
- 可以一键恢复配色跟随 VS Code。自定义外观和高亮总开关互相独立，关闭高亮不会丢失字体与正文颜色设置。

## 可调、克制的文字高亮

默认只对**配对引号中的对话**使用柔和的字符串色，叙述正文保持编辑器原色。默认不加底色、加粗、缩进或额外行距。

| 类型 | 默认 | 识别方式 |
| --- | --- | --- |
| 对话 | 开启 | `“…”`、`「…」`、`『…』`、英文双引号；支持嵌套及跨行配对 |
| 单引号内容 | 关闭 | `‘…’`，可用于区分作者以单引号标出的内心独白或引用 |
| 人物名 / 地点 / 关键词 | 词表为空 | 用户填写字面词表；优先匹配较长的人名，不执行正则表达式 |

每一类都有**独立开关、颜色和强度（不透明度）**，还有总开关。颜色留空时随阅读配色方案 / VS Code 明暗主题调整；也可指定 `#RRGGBB` / `#RRGGBBAA`。关键词优先于引号颜色，单引号可在对话内部独立着色。

这些是本地的标点 / 词表规则，不上传正文、不调用 AI，也不声称能准确识别说话者或心理活动。未闭合的引号不会把后面的整章染色。

## 登录

打开书城 → 右上角「登录」→「开始扫码登录」，用抖音或番茄小说 App 扫码确认。书架和历史记录可本地使用；登录后可同步云端书架与章节进度。

## 本地开发与验证

```sh
npm ci
npm test
npm run test:integration
npm run package
```

- 单元测试覆盖全文保留、引号嵌套 / 转义 / 断句、关键词、目录、进度与配置约束。
- 集成测试启动**独立用户数据目录**下的真实 VS Code，不修改日常 VS Code 的设置、登录或书架；使用原创离线样章，不依赖番茄接口可用性。
- 集成测试检查原生文本标签页、用户输入只读、字体与普通代码页的实际渲染值一致、小说自定义字体不污染代码页、配色及高亮实时更新、查找、切章、多章合并与页内跳转、改变合并数保留位置、故障重试、并发请求和跨进程续读，并保存截图与 JSON 验证结果到 `.test-data/`。
- Windows 默认使用本机 VS Code；其他环境可指定 `VSCODE_EXECUTABLE_PATH`。指定 `VSCODE_VERSION` 可用相应版本运行兼容性测试。
- 可选在线冒烟验证：设置环境变量 `FANQIE_LIVE_ONLY=1` 后运行 `npm run test:integration`，只读取一个公开章节，验证真实接口到原生阅读器的完整链路。
- 打包生成本地 `.vsix`，不会自动发布或推送。版本号分支仍校验版本匹配；`main` / 功能分支也可本地打包。

## 已知边界

- 部分网络环境下番茄接口会返回空响应，原有 SSR 降级逻辑保留；加载失败不会覆盖正在阅读的章节，可以重试。
- 付费 / 锁定章节只显示官方接口实际返回的可读内容，完整阅读权限仍由官方平台决定。
- 不提供番茄 App 专属的章评 / 段评；状态栏「书评」打开的是书籍评论。
- 阅读外观使用当前文档的原生编辑器配置；语言专属设置仍按 VS Code 规则应用，小说语言 ID 为 `fanqie-novel`。
- 本项目仅用于个人学习研究，请遵守番茄小说服务条款，勿用于批量抓取。
